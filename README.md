# mini-projects

Small experiments and one-off projects, one folder each.

| Project | What it is |
|---|---|
| [awwwards/building](awwwards/building) | "Kaide Yapı": a scroll-driven 3D building page (Three.js, GSAP, Vite); the Blender source of the tower is in `blender/` |
| [water-simulation](water-simulation) | "Pelagic": an open-ocean simulation on WebGL 2 (GPU FFT waves, atmosphere, foam), with a standalone single-file build |
| [su](su) | "Okyanus": the single-file ocean shader that Pelagic started from |

Each project keeps its own `package.json` where it has one; run `npm install`
inside that folder. Dependencies and build output are not committed.
